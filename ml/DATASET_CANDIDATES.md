## Phase 9 research update (2026-10-02)

New leads were reviewed at source-page level. The Kaggle e-waste dataset is the closest reported match for chargers, laptops and monitors, but a preprint's 2,404-image claim is not a license or file audit; no commercial license or per-class counts were verified. The Roboflow listing displays CC BY 4.0 and labels that include adapters, chargers, cables and audio accessories, but it has zero published dataset versions and no per-label counts. TrashBox has 2,883 broad e-waste images but no license statement on the inspected repository page. TrashNet++ claims CC BY 4.0 and includes cable images, but its e-waste label is broad and its README provides no validated subtype counts. MMEWaste and XBAT+ provide no visible license; MMEWaste also says its complete data remain confidential. None changes the Phase 9 gate.

## Selection for Phase 9

Do not add a new training dataset based on card-level claims alone. Existing six-class source is already audited for the current baseline. Bower is the strongest phone-camera external validation candidate for the broad binary e-waste-vs-household decision; it is not sufficient for subtype expansion. GIZ is a potential laptop/computer source but not yet acquired or audited and lacks charger class. No dataset found in this pass establishes enough clean charger/adapter examples to train and independently test that class. Consequently Phase 8 stops before training V2.
