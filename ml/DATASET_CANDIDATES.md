## Selection for Phase 8

Do not add a new training dataset based on card-level claims alone. Existing six-class source is already audited for the current baseline. Bower is the strongest phone-camera external validation candidate for the broad binary e-waste-vs-household decision; it is not sufficient for subtype expansion. GIZ is a potential laptop/computer source but not yet acquired or audited and lacks charger class. No dataset found in this pass establishes enough clean charger/adapter examples to train and independently test that class. Consequently Phase 8 stops before training V2.
