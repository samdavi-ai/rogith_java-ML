# RecoLens final dataset source register — Phase 10

Audit date: 2026-10-02. The only source used by the existing candidate V2 is the locally acquired Roboflow export identified by its embedded `data.yaml` as project `e-waste-uvzkj`, version 5, and declared CC BY 4.0. The related Mendeley record is [Custom Bangladeshi E-Waste Image Dataset for Object Detection and Recognition](https://data.mendeley.com/datasets/77383kmdnw/1), DOI [10.17632/77383kmdnw.1](https://doi.org/10.17632/77383kmdnw.1). Counts below separate source-record volume from actual candidate files. No dataset is approved for a new training run in Phase 10.
